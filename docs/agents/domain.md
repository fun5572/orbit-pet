# Domain Docs

This repository uses a single-context domain-documentation layout.

## Before exploring

Read these files when they exist:

- `CONTEXT.md` at the repository root
- Relevant ADRs under `docs/adr/`

If they do not exist, proceed silently. Create them only when project terms or
architectural decisions are actually resolved.

## Vocabulary

Use domain terms as defined in `CONTEXT.md`. Avoid introducing synonyms that
conflict with the documented glossary.

## ADR conflicts

If proposed work contradicts an existing ADR, surface the conflict explicitly
instead of silently overriding it.
